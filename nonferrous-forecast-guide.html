有色金属行业业绩预测分析框架

写给行业分析小白的使用手册 · 口径：A股有色金属上市公司（申万一级：工业金属/贵金属/能源金属/小金属/金属新材料） · 配套页：利润格局分析 · 48家双情景测算 · 编制日期 2026年8月27日 · 专业名词首次出现均加粗，可在此页「名词速查」区集中查阅

核心结论（TL;DR）

  • 一句话框架：有企业绩 = （金属价格 − 成本）× 产量，再叠加扩张项目投产进度与减值/套保扰动。它是最"物理"的行业——利润几乎完全由量价成本三要素决定，没有医药那么复杂的管线期权。
  • 八个预测维度：① 金属价格判断（量价利的第一因子）；② 矿产产量与产能释放节奏；③ 成本曲线位置；④ 资源储量与增储前景；⑤ 扩产项目投产时间表；⑥ 减值、套保与一次性损益；⑦ 产业链位置（矿端/冶炼/加工）；⑧ 宏观与政策环境。
  • 与医药框架的本质区别：医药看"研发管线的概率"，有色看"商品价格的周期"。有企业绩的波动核心是价格弹性——金价涨1倍，纯金矿公司的利润可以涨3-5倍（经营杠杆放大），这在医药行业不存在。
  • 实操三步法：先从年报"分产品收入表"算出业务结构（铜/金/锂各占多少）→ 再用"（价格−成本）×产量"分别测算各业务的利润弹性 → 最后叠加扩产项目投产时间表做未来三年的量的预测。

一、动手前先分清：这家公司挖的是什么矿？

申万口径下有色金属分五个子板块，商业模式差异极大——最容易被小白混淆的是"有矿的"和"加工的"
子板块典型A股公司赚钱逻辑（一句话）预测业绩最该看的维度
贵金属（金/银）紫金矿业*、山东黄金、赤峰黄金、中金黄金挖金矿石提炼出售，利润≈（金价−开采成本）×产量，金价弹性极大①金价 + ②矿产金产量 + ③成本
工业金属（铜/铝/锌/铅）紫金矿业、洛阳钼业、江西铜业、云铝股份铜跟随全球电气化与AI算力需求，铝叠加国内产能天花板逻辑①铜铝价 + 全球供需 + ⑦矿/冶炼位置
能源金属（锂/钴/镍）天齐锂业、赣锋锂业、华友钴业新能源电池原料，强周期+高波动，2022顶→2024深亏→2025出清回升①锂价周期位置 + ⑥低价库存减值
小金属（钨/钼/锡/锑/稀土）北方稀土、厦门钨业、湖南黄金(锑)体量小但战略属性强，供给受限时价格弹性惊人（如锑）①价格 + ⑧出口管制/收储政策
金属新材料/加工宝钛股份、博威合金、铂科新材不靠矿，靠把金属加工成高附加值材料赚加工费——看的是订单不是价格下游订单 + 毛利率稳定（更像制造业）
*注：紫金矿业是铜金双轮驱动，跨贵金属与工业金属两栏。
为什么这张表最重要：小白最大的误区是把"江西铜业"当"铜矿股"——它实际上大部分收入是冶炼费赚加工钱的，铜价涨它赚得远比纯矿企少。先看清楚公司处在产业链哪一环，再看维度。

          + 新项目投产贡献⑤ − 减值与一次性损益⑥

⑦ 产业链位置赚的是矿的钱、冶炼的钱还是加工的钱？分产品毛利率结构（矿山毛利80%+ vs 冶炼毛利3-5%）

用法：给每家公司逐维打分加权合成"业绩确定性分数"。研究金矿股把①③调高，研究锂企把①⑥调高，研究加工材企业把下游订单调高（价格维度权重调低）。

三、八维详解：每个维度看什么、在哪看、如何判断好坏

每个维度都给出"好的信号 / 危险信号"，配公司实例
1金属价格判断
关键问题：这个矿挖出来的东西，未来一两年会更贵还是更便宜？
有企业绩第一因子，占预测工作量的60%。三种分析流派：（a）宏观派——金看美元与实际利率（美元弱则金强）、铜看全球制造业周期与中国电网投资；（b）供需派——看机构供需平衡表（如铜2025-2027年矿端缺口持续），供给矿山品位下滑+新矿稀缺是长期逻辑；（c）事件派——出口管制（锑、镓）、矿山罢工、资源国政策扰动。散户实用做法：跟踪各大券商年度策略的价格中枢预测，取平均做基准情景，±20%做乐观/悲观情景。
好信号：供需平衡表连续3年短缺、矿端资本开支不足（未来供给少）。
危险信号：价格已涨至历史90%分位以上、下游开始减产对抗高价。
2矿产产量与自产率
关键问题：利润表里有多少是"自己挖的矿"贡献的？
必须区分矿产产量（自己挖矿，吃价格弹性）与冶炼/加工量（代工赚加工费，不吃价格弹性）。紫金矿业2025年矿产铜108.5万吨、矿产金90吨——这些"矿产"开头的数字才是利润引擎；江西铜业收入三千亿但矿端自产铜只有二十来万吨。实操：年报"主要产品产量表"逐项抄下来，标出哪些是矿产、哪些是冶炼；未来产量预测看公司自己的"三年产量规划公告"（矿企一般会披露），打折80%更稳妥。
好信号：矿产产量年增10%+、自产矿占收入比例上升。
危险信号：产量停滞、靠冶炼规模撑收入（增收不增利）。
3成本曲线位置
关键问题：同样的价格，谁的利润厚？
矿业是"同品竞争"——大家卖一样的金属，成本低者恒强。关键指标是单位销售成本（元/克金、元/吨铜）与C1成本（现金成本，行业比较通用口径）。看两个数：①公司自身成本变化趋势——地下矿转露天、品位下降、人工通胀都在推高成本；②公司在全球成本曲线上的分位——90分位成本决定了"价格底"：价格跌到90分位时，最差的10%矿山亏损停产，价格获得支撑。量化弹性示例：金价600元/克、某矿完全成本300元/克，金价涨20%到720元，单克利润从300涨到420——利润涨40%，弹性是价格的2倍（这就是杠杆公式：放大倍数=1+价格涨幅×价格/(价-本)的关系，直觉理解为"利润基数小所以翻倍快"）。
好信号：单位成本持平或下降（新矿品位高、规模化）、成本处全球前1/4分位。
危险信号：成本逐年爬升（老矿品位下降）、高价收购的低品位矿拖累。
4资源储量与增储前景
关键问题：这是门能做多少年的生意？
矿是会挖完的。看权益储量（注意"权益"二字——参股矿山的储量按持股比例折算）与储采比（储量÷年产量=还能挖多少年，一般>20年算资源雄厚）。但比静态储量更重要的是增储能力：紫金过去十年储量产量双增靠的是持续并购（卡莫阿铜矿、Timok铜金矿等世界级项目）。对小白，看公司"资源储量"章节的三年变化趋势即可：储量在涨的公司才有长期产量故事。
好信号：储采比>20年且持续通过勘探/并购增储。
危险信号：储采比<10年、资本开支全部用于维持现有产量。
5扩产项目投产时间表
关键问题：明后年的"量增"从哪里来、什么时候来？
有色行业"未来业绩"最确定的部分是在建项目的投产节奏——不像药企管线有成败概率，矿建好了就会出矿。要收集的信息：项目名称、设计产能、投产/达产时间、权益比例。注意两个坑：①投产≠达产——投产后通常要1-2年爬坡到设计产能，预测时按爬坡曲线（首年50%、次年80%、第三年满产）折算；②权益比例——持股51%的项目利润只有51%并表。海外项目还要关注所在国政策（税收、出口、国有化风险）。
好信号：未来2年有多个大项目接力投产、爬坡进度符合公告指引。
危险信号：项目一再延期（尤其海外项目）、达产后成本显著高于预期。
6减值、套保与一次性损益
关键问题：账面利润里有多少"噪音"，会不会突然暴雷？
有色公司利润表的三颗雷：（a）存货跌价减值——锂价暴跌时，锂盐厂高价囤的锂精矿要计提跌价（天齐锂业2024年巨亏主因之一）；（b）套保浮亏——公司在期货市场做空套保锁价，价格暴涨时套保端亏损会抵消现货利润；（c）商誉与资产减值——高价并购的矿山在价格下行期计提减值。实操：对比"扣非净利润"与"归母净利润"差异，差异大的年份翻公告找原因；看存货余额与原材料价格走势的背离。
好信号：扣非与归母差异小、减值计提充分（洗澡后轻装上阵）。
危险信号：存货随价格下跌而增加、多年未计提减值的老矿企。
7产业链位置（矿/冶炼/加工）
关键问题：这家公司吃的哪一段利润？
同一条产业链三种生意：①矿山——毛利率70-90%，吃价格弹性，周期股本色；②冶炼——赚加工费（TC/RC），铜冶炼费近年因矿端紧张被压到历史低位，铜价再涨冶炼厂也难受益，毛利率仅3-5%；③加工材——把金属做成板材/箔材/合金，赚加工费+技术溢价，毛利率稳定，估值更像制造业（如铜箔、铝箔、钛材）。快速鉴别：看分产品毛利率——毛利率与金属价格高度同步的是矿，毛利率常年个位数稳定的是冶炼，毛利率30%+且稳定的是高端加工。
好信号：矿端自给率高、或加工端有独特技术壁垒（高端钛材/高温合金）。
危险信号：纯冶炼企业遇上加工费下行周期（收入涨利润不涨）。
8宏观与政策环境
关键问题：有哪些"天上的变量"会改变整个行业的剧本？
四大宏观变量：①美元与利率——美元弱+降息周期利好金银铜（以美元计价）；②中国需求——全球铜铝一半以上需求在中国，电网投资、地产链、新能源车决定边际增量；③供给端政策——国内电解铝4500万吨产能天花板（供给锁死→利润率抬升）、小金属出口管制（锑/镓/锗管制后价格暴涨）；④资源国政治——智利铜矿国有化、非洲矿业税、印尼镍出口政策。这些变量不能精确预测，但必须写进情景分析：同样的公司，在"美元走弱+中国电网加码"情景与"美元走强+地产下滑"情景下的业绩可以差一倍。
好信号：资源分布多国、业务同时受益于新能源与电网两大趋势。
危险信号：单一矿山占比过高（地缘黑天鹅一击致命）、全押注单一价格情景。

四、名词速查手册（按重要性排序）

▲ 量价成本核心类
矿产产量（自产矿）：公司自己矿山采出的金属量（吨/万吨）。有企业绩的"量"只算这个——外购矿再冶炼不算。紫金"矿产铜/矿产金"即此口径。类比：自己家母鸡下的蛋。
选矿/冶炼：把矿石加工成纯金属的过程。冶炼厂赚加工费，不赚金属涨价的钱。类比：把别人家的麦子磨成面粉，赚磨面钱。
TC/RC（粗炼/精炼费）：冶炼厂处理铜精矿收取的加工费（美元/吨）。矿少冶炼厂多时TC被压低——2025年铜TC跌至负值区间，冶炼厂普遍亏损。
单位销售成本 / C1成本：每生产一吨（或一克）金属的经营现金成本。跨公司比较盈利能力用。C1＝采矿+选矿+管理现金成本，不含折旧。
成本曲线（Cost Curve）：把全行业所有矿山的成本从低到高排成的曲线。价格跌破某矿山成本→它停产→供给收缩→价格获支撑。90分位成本常被视为长期价格底。
品位（Grade）：矿石里含金属的比例（如铜矿0.5%品位=每吨矿石含5公斤铜）。品位越高越好采越赚钱；老矿山品位逐年下降→成本上升。
储采比（R/P）：剩余储量÷年产量=按当前速度还能挖几年。>20年资源雄厚，<10年面临枯竭。
权益储量 / 权益产量：按持股比例折算后的储量产量。持股51%的矿山，100万吨储量只算51万吨。"权益"口径才能反映真实归属。
▲ 项目与扩张类
投产 / 达产 / 爬坡：投产=开始出矿；达产=达到设计产能；中间的逐步提升过程叫爬坡（通常1-2年：首年50%→次年80%→满产）。预测产量必须按爬坡折算。
绿地/褐地项目：绿地=从零新建矿山（风险高周期长，5-10年）；褐地=现有矿山旁扩建（风险低见效快）。褐地项目兑现确定性更高。
JORC / NI 43-101：澳洲/加拿大的矿产资源储量披露标准。海外并购项目的储量数据要认准这些标准认证，否则数字可能注水。
▲ 价格与市场类
LME / SHFE / COMEX：伦敦金属交易所/上海期货交易所/纽约商品交易所——全球与国内金属定价中心。LME铜价是全球铜价基准。
内外价差 / 沪伦比：国内价格÷国际价格的比值，反映进出口窗口与国内供需强弱。
价格分位数：当前价格处于过去N年（通常10年）价格区间的百分位。90%分位=比过去十年90%的时间都贵——警惕但未必见顶。
Back / Contango（升水/贴水结构）：期货近月合约比远月贵=Back（现货紧张信号）；反之为Contango（宽松信号）。看结构比看单日价格更能反映供需。
实际利率：名义利率−通胀预期。实际利率下行→持有黄金的机会成本下降→金价涨。这是金价预测第一公式。
▲ 财报与交易类
归母净利润 / 扣非净利润：归属母公司股东的净利润 / 剔除一次性损益后的净利润。有色公司两者差异常来自减值与套保，看趋势优先用扣非。
套期保值（套保/Hedge）：在期货市场反向开仓锁定未来售价，防价格下跌。副作用：价格暴涨时套保端亏损、少赚涨价的钱。有些金矿公司因"不套保"在金价上行期利润弹性反而更大。
资产减值：存货跌价、矿山资产贬值时在利润表中计提的损失。价格下行周期的"利润杀手"，但一次性计提后反而轻装上阵（市场称"洗澡"）。
经营杠杆（价格弹性）：利润变动幅度÷价格变动幅度的倍数。因成本相对固定，价格涨20%利润可涨40-60%——弹性大小取决于"价−本"的利差基数。利差越薄弹性越大。
PE（市盈率）/ 周期股PE陷阱：股价÷每股利润。周期股在利润巅峰时PE最低，看似便宜实则是卖点；利润谷底时PE最高，看似贵实则是买点——周期股要用"周期平均利润"或PB看估值。
PB（市净率）：股价÷每股净资产。矿业公司资产主要是矿山，PB是周期股更可靠的估值锚。
▲ 宏观与政策类
美联储 / 美元指数：美国央行/美元对一篮子货币的强弱指数。降息+弱美元=金银铜的顺风环境。
央行购金：各国央行增持黄金储备。2022年起全球央行年购金超1000吨，是本轮金价牛市的核心买盘。
电解铝产能天花板：国内电解铝产能红线约4500万吨，已接近封顶——供给锁死+需求增长=行业利润率中枢抬升，是铝板块的长期逻辑。
出口管制：对战略金属限制出口（锑/镓/锗2024-2025年管制后国际价格暴涨）。持有被管制品种的公司直接受益。
资源民族主义：资源国政府提高矿业税、强令国有化、限制原矿出口（如印尼镍矿禁止出口倒逼本土建厂）。海外矿占比高的公司必须评估此风险。

五、实战演示：用八维框架快速体检一家公司（以紫金矿业为例）

演示框架用法 · 数值为公开资料整理*，完整测算见 48家双情景测算
维度紫金矿业（601899）现状速览评分
① 金属价格铜金双轮：2025-2026年金价新高+铜供需缺口扩大，双价格周期共振上行优
② 产量与自产率2025年矿产铜108.5万吨（全球前四）、矿产金90吨（全球前六），矿端利润占比高优
③ 成本位置矿产金成本处于全球成本曲线前1/4，铜成本中位偏下且规模效应递减中良
④ 储量增储权益铜金储量国内第一，卡莫阿、Timok等世界级矿持续增储优
⑤ 扩产节奏卡莫阿三期、巨龙二期等陆续投产，公司三年产量规划明确（铜150万吨/金100吨方向）良
⑥ 减值套保基本不做金价套保（上行期弹性足）；历史并购多，需跟踪商誉减值中性
⑦ 产业链位置矿端为主+冶炼板块托底，冶炼占比持续下降良
⑧ 宏观政策资产遍布17国（地缘分散化是优点也是管理难点）；受益弱美元+央行购金中性偏正面
把这个例子变出预测：量（产量规划×爬坡折算）× 价（机构铜金价格中枢预测）− 成本（单位成本×产量，按通胀2-3%上调）＝ 分板块利润 → 加总即公司利润，再对价格做 ±15% 情景敏感性（正是《48家双情景测算》的方法：黄金2年×2/4年×4 等情景假设）。此前测算显示：极端金价情景下赤峰黄金弹性第一，紫金因"铜金双轮+量增"成为压舱石——弹性选弹性矿企，确定性选龙头。

六、小白最容易犯的六个错误

每一个都是真实投资人反复踩过的坑
#错误做法正确姿势
1把冶炼厂当矿企：看到铜价暴涨就买江西铜业先看分产品毛利率区分矿/冶炼/加工，价格弹性只属于矿端
2用市盈率（PE）判断周期股贵贱：利润巅峰PE=5觉得"便宜"周期股用PB+周期平均利润估值；低PE+价格高位=典型的周期顶部特征
3把设计产能当实际产量：项目公告"年产50万吨"直接计入明年业绩按投产→爬坡→达产的节奏折算（首年50%），海外项目再打八折
4只看收入增长：冶炼收入随金属价格水涨船高看矿产产量与扣非利润——"增收不增利"是冶炼/加工企业的常态
5忽视权益比例：把参股大矿山的储量产量全部算进公司统一换算成权益口径；跨国项目另计税收汇出与地缘风险折扣
6单点预测价格：押注"金价必到XXX元"的单一路径用基准/乐观/悲观三情景测算业绩区间，仓位按悲观情景的承受力配置
