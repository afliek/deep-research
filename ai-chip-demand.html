叁规律提炼：token 与芯片的非线性脱钩

历史数据归纳 + MoE/稀疏化推动的"算力/芯片脱钩"趋势

核心非线性：算力增长对芯片增长的"溢价"已从 2× 上升至 8-10×——同样一组芯片，每年服务/产出的 token 已翻 5-7 倍。

◆推动"脱钩"的四股力量

  • 算法效率（最大杠杆）：预训练 3×/年（Epoch），推理侧叠加 MoE+量化+投机解码 → 综合 3-5×/年。
  • 硬件利用率：机柜级（NVL72/GB200）、推理专用卡、存算一体（SRAM/NAND PIM 量产中）→ 1.1-1.3×/年。
  • 库存与超卖周期：2024 上半年缺货、渠道囤货，2025 进入消化 → 出货"虚低"于实际需求。
  • 模型路由与小模型化：约 80% 简单请求由 7B/13B 小模型承担，仅长尾请求上 Frontier → 单 token 平均 FLOP 显著下降。

◆历史规律归纳

  • token 算力增长 ≈ 2-10×/年（训练 5×、推理 30×、全球混合 5-10×）
  • 芯片需求增长 ≈ 1.3-2×/年（出货量口径；营收 2-3× 含单卡价格因子）
  • 比率 3-8× 并随算法效率改善呈单调扩大——这就是"算力/芯片脱钩"的量化定义

规律："token 算力 10× 与芯片需求 1.5-3× 不是同向放大，而是非线性脱钩——中间被 3-5× 算法效率、 1.2-1.5× 单卡性能、1.1-1.3× 系统效率三重除数吸收；余下的 1.5-3× 即为物理芯片需求。"

伍核心结论

数据驱动的五条关键判断

01

基准倍数区间 1.5-3×——以 token×10 为输入、中性参数组合下芯片需求倍数落在 1.7-3×；乐观 1.7×、保守可达 5×。给出区间而非定值是关键，因为算法效率参数仍在快速变化。

02

三重除数贡献量化——算法效率 ≈2-3× 是最大杠杆，单卡算力 1.4-1.5× 次之，系统利用率 1.1-1.3× 居末；三者相乘方使 token×10 收敛到芯片×1.5-3×。

03

训练/推理分流——训练侧 1.2-2.5×（前沿跑线绑定最先进卡）、推理侧 1.5-4×（小模型+缓存摊薄每 token FLOP）；聚焦训练卡则更靠近 1.5-2×，泛指全集（含 L40S、ASIC）可上探 3-4×。

04

脱钩是结构性而非周期性的——2022→2025 算力/芯片比率从 1.8 扩大至 8-10× 且仍上升，意味着 AI 行业单位算力资本开支强度持续下降；芯片估值宜引入"每 token 收入"口径替代"每瓦/每美元 FLOPs"。

05

2026E 最大不确定性项是算法效率——MoE 与投机解码渗透若超预期，倍数可下探 1.2-1.5×；HBM4/CoWoS-L 良率不及预期则可上探 4-5×。追踪指标：每 token 平均 FLOPs、CoWoS 月度产能、头部厂商季度 token 披露。

当 token×10 时，物理芯片需求仅 ×1.5-3 —— 中间被 MoE、量化、缓存、机柜级、存算一体五重效率杠杆吸收 AI 资本开支"算力通胀但芯片通缩"的结构性原因
