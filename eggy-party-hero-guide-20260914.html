读前必看：这里的"相生相克"指什么

Read First

先把话说清楚，避免误会。

先纠正一个常见的错认

《蛋仔派对》里的"蛋仔"绝大多数是外观皮肤——几百上千款，皮肤之间没有任何属性差异，也不存在相生相克。真正带技能、能对战、有强弱关系的，是"超燃系列玩法"里的超燃蛋仔（游戏内叫"英雄"）。本页讲的是后者。

官方没有硬性属性克制

超燃竞技场不是石头剪子布式的"属性环"。官方从来没出过"水克火"这类硬性克制表。玩家口中的"相克"，本质是两类东西：

  • 机制克制——技能交互上的克制，比如隐身克无视野、霸体克控制、打断克读条大招。这部分是硬逻辑，稳定成立。
  • 分段共识——高分段玩家与攻略社区总结的强弱对位，会随版本平衡性调整变动。这部分是经验，不是定论。

本页把两者分开标注：机制克制写进"克制关系"章节，共识类写进角色卡。

数据来源与时效
  • 英雄名单：以官方 2026 年 8 月 6 日更新公告公布的 18 位超燃大乱斗英雄为最新基准，并合并官方更新公告、官方玩法介绍页中出现过的角色。
  • 角色定位与技能：官方更新公告、网易官方玩法介绍、百度百科"超燃蛋仔"词条。
  • 机制与对位：玩家社区攻略与高分段共识（标注为"共识"）。
  • 游戏每 1–2 个月做一次平衡性调整，数值强弱会变，但机制层面的克制关系基本稳定。
  • 带「资料有限」标记的卡片，是官方只公布了角色名与定位、技能细节未公开的角色，我没有编内容。

新手入门：从上手到不坑队友

Beginner Guide

如果你是第一次进超燃竞技场，这一节比后面的角色数据更该先看。看完这页你就知道选谁、买什么卡、站哪里。

三句话搞懂这个模式在玩什么
  • 怎么组局：8 名玩家，两两一队，共 4 队。每人选一个超燃蛋仔上场，在太空 / 工厂 / 运动 / 音乐四张图里打 2V2。
  • 怎么变强：每回合开始从 3 张卡里挑 1 张，一共 8 个回合。卡分两种——加属性的装备卡、改机制的功能卡。
  • 怎么算赢：除了各自的血条，每队还有一个共享的"燃力值"。每回合打输的队伍扣一部分燃力值，扣到 0 就整队淘汰。活到最后的那队赢。

另外场上有毒圈会慢慢缩小，掉到圈外会持续掉血——所以别恋战，注意圈。

01

选人：第一次别选刺客和法师

新手最容易死的就是脆皮。先在坦克、辅助、简单战士、射手里挑一个——血厚或者站得远，容错高。刺客和法师吃操作和意识，等你熟悉地图再说。

02

买卡：先堆血，再堆输出

新手的通病是把 8 张卡全买伤害，结果一进场就蒸发。前 2–3 张优先拿血量、护甲、减伤类，站得住才有输出。远程角色可以适当早点补伤害。

03

打架：永远别离开队友

这模式是 2V2，落单就等于送。跟着队友走，坦克往前顶、远程往后站。队友被集火就回身帮忙，别贪那个人头。

最推荐新手先练的 5 个角色

标准是：技能简单、血厚或者站得远、犯错不容易死。

蛋小黄 · 坦克技能就三招：放剑气、原地转、滚过去撞人。血厚还有盾，死了也能怪技能简单。用来练"什么时候该冲"这件事最好。
蛋小绿 · 辅助核心玩法是"挂"在队友身上回血，不用你去正面拼操作。站在队友后面丢爱心、关键时刻变形术打断对面大招就行。
元气丸子 · 战士一根鸡腿走天下：击飞、减速、蓄力砸。招数直观不绕，近身打着顺手，是最好理解的战士。
蛋小粉 · 射手全游戏射程最远的角色，站后面一直点就行。练的不是手速是走位——记住一件事：永远别让敌人贴近你。
圆圆子 · 法系坦克打中敌人会掉出回血糯米团，捡起来就回血，血越厚技能范围还越大。是最不容易死的一个，新手拿来熟悉地图很合适。

我该站哪？一句话记职业

坦克我站最前面，先冲、先挨打
战士我跟着前排上，谁冒头打谁
法师我站中间偏后，技能往人堆里丢
射手我站最后面，离敌人越远越好
刺客我绕到对面后面，专打他们的后排
辅助我跟着队里最能打的那个人
新手最容易犯的 5 个错
  • 落单——最常见的死法。你以为你在绕后，其实是在送。
  • 卡全买输出——前期站不住，伤害再高也打不出来。
  • 追着人跑——追进对面阵地，等于把自己送进包围圈。
  • 大招乱交——读条型大招被打断就白交，等对面控制技能用完再放。
  • 两人选同一类型——两个射手没人开团，两个坦克打不死人。一攻一守最稳。

底层逻辑：六职业的克制循环

Class Cycle

超燃竞技场的平衡不是靠属性，是靠"机制三角"——爆发、坦度、射程互相咬。理解这个三角，几乎所有对位你都能自己推出来。

图 1　超燃竞技场的机制三角。箭头方向为"克制方指向被克制方"。

三条推论，直接拿去用
  • 你是刺客：别正面接坦克，绕开前排去打射手和法师。一旦坦克把控制交在你身上，你这局基本没了。
  • 你是射手/法师：先把坦克耗到半血再谈输出，但眼睛要盯住刺客。射程是你唯一的护身符。
  • 你是坦克：你不是去杀人的，你是去卡住刺客那条路，让你的后排能站住。开团时机比伤害重要。

反向记：被克制时怎么破
  • 被隐身点名 → 往有范围伤害的队友身边靠，或者贴着墙走减少可接近角度。
  • 被钩索/控制链锁 → 留一个位移技能专门用来断链，不要用来追击。
  • 被风筝耗死 → 别追，退到建筑物和草丛后面，等对面进你的射程。
  • 大招总被打断 → 别先手开大，等对面的打断技能交完再上。

配队模板：怎么把相生用起来

Team Comps

超燃竞技场的配队逻辑只有一条：一个负责控住人，一个负责打死人。以下模板是玩家社区验证过的组合，你可以直接把角色换成同类型的其他角色。

经典控杀流

魔鬼蛋 + 蛋小粉

魔鬼蛋冲锋撞飞并过肩摔控住，蛋小粉在射程外标记输出。官方玩法演示里点名的组合。

原理：硬控创造输出窗口 → 射程优势收割。缺点是两人都没有位移，被刺客绕后会很难受。

绕后收割流

蛋小蓝 + 蛋小黑

蛋小蓝远程压制血线并用大招圈住敌人，蛋小黑隐身绕后收残局。

原理：控场 + 刺客联动。克制对面抱团推进，但两人都脆，前期容易被强势前排压制。

前排续航流

蛋小黄 + 蛋小绿

蛋小黄正面冲锋开团，蛋小绿全程附身回血、变形术反制对面关键角色。

原理：坦度 + 治疗形成不死循环。变形术还能打断对面大招，是最稳的一套。

压制控场流

饶舌诗人 + 失心熊

失心熊钩索把对手拽出阵型并强控，饶舌诗人紧跟范围输出，对手出圈还会被眩晕。

原理：强制位移 + 范围伤害。进攻防守都强，但对操作默契要求高。

钩索开团流

失心熊 + 连环控制位 + 爆发输出

三排思路：失心熊先手钩人，控制位接控链，爆发位把被控住的敌人打死。

原理：控制链叠加。注意失心熊大招怕打断，敌方打断技能多时要后手进场。

反制上面这几套

防守反击思路

面对控杀流：拿有位移或免控的角色，别站在一起。面对钩索流：留位移技能专断钩索，或者选无法选中机制的角色。

原理：所有控制流都怕两样东西——位移，和打断。

选人的一条铁律

别两个人选同一个类型。两个射手法师 = 没人开团，团战一触即溃；两个坦克 = 打不死对面，只能拖到毒圈。一攻一守、一控一输出，永远是最省心的搭配。
