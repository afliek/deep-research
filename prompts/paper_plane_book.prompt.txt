【来源】用户李侠在 WorkBuddy 会话中提供的原始提示词，一字未改记录如下：

使用 Three.js 创建一个精美、可交互的 3D 网页场景。
场景主体：
1. 一本打开的复古精装书，平放在木质桌面上。
2. 书页之间有一架精致的白色折纸纸飞机。
3. 纸飞机能够从书中缓慢飞出，在书本上方飞行一圈，然后重新飞回书页之间。
视觉风格：
- 电影级 3D 渲染质感，精致但不过度复杂。
- 温暖奶油色调，复古书房氛围。
- 柔和的窗边侧光，轻微体积光。
- 空气中有少量细微尘埃粒子。
- 纸张纹理清晰，书页有自然厚度和轻微弯曲。
- 木桌材质细腻，有柔和环境光遮蔽和真实阴影。
- 背景简洁干净，不要杂乱物体。
交互要求：
- 使用 OrbitControls，允许用户旋转、缩放、平移观察。
- 场景有自动旋转展示，用户操作时暂停自动旋转。
- 纸飞机运动轨迹平滑，像真实纸飞机一样轻微倾斜、摆动。
- 书最后在纸飞机飞回后缓慢合上。
动画逻辑：
1. 开始时纸飞机位于打开的书页之间。
2. 纸飞机沿平滑曲线缓慢滑出书本。
3. 在书本上方优雅飞行一圈。
4. 沿弧线飞回书页缝隙。
5. 书本最后轻轻合上，动画循环播放。
技术要求：
- 使用 Three.js r150+。
- 使用 GLTFLoader 或基础几何体构建书本和纸飞机；如果没有模型，使用 BufferGeometry 程序化创建。
- 使用 MeshPhysicalMaterial 或 MeshStandardMaterial，纸张材质要有轻微粗糙度和次表面散射感。
- 使用环境贴图提升反射质感。
- 阴影类型为 PCFSoftShadowMap，阴影柔和。
- 代码结构清晰，包含场景、相机、渲染器、灯光、控制器、动画循环。
- 适配桌面端和移动端，加入响应式 resize。
- 无文字、无 UI 按钮、无水印。
最终效果要求：
画面精美、材质细腻、动画流畅、构图干净，纸飞机和书是绝对视觉中心。
