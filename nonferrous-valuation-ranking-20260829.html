◆ 核心结论

  1. 被低估程度最高的是华友钴业（603799），低估 +79.0%。PE-TTM 仅 11.0x、PB 1.49x，而其 PB 处于自身 2018 年以来 9.9% 的极低分位——即比过去 8 年 90% 的时间都便宜。2026H1 营收 555.7 亿、净利 35.1 亿、ROE 年化 14.1%，盈利扎实，不是"便宜的垃圾"。
  2. 低估榜前列高度集中在工业金属：前 20 名中工业金属占 7 席（明泰铝业、中孚实业、焦作万方、顺博合金、南山铝业、创新新材、天山铝业），共同特征是 PE 8–18x、PB 1.0–2.0x、ROE 年化 11–32%。这是本轮有色行情里最没有被资金定价的一块。
  3. 最贵的是 *ST利源（−100.9%）、宜安科技（−89.1%）、华阳新材（−81.7%），均为亏损 + 净资产被侵蚀导致的 PB 虚高（华阳新材 PB 43.7x、负债率 93.3%），属价值陷阱而非成长溢价。
  4. 主题股估值已透支：云南锗业 PB 42.4x、博迁新材 21.8x、晓程科技 12.8x，均处自身历史 PB 90%+ 分位，模型给出 −55% 至 −58% 的高估判断。
  5. 板块整体已不便宜：145 家低估幅度中位数 -1.2%，78 家高于模型中枢、67 家低于。相对便宜的机会是结构性的，不是板块性的。
一、估值模型（完整披露，可复算）
所有比较均在申万二级子行业内部进行，避免用铝的估值去衡量锗。子行业内按年化 ROE 升序分层（样本 ≥24 家分 3 层，12–23 家分 2 层，<12 家不分层），取同层 PB 中位数作为横向基准 PB_peer——低盈利公司只与低盈利同业比，这一步是为了杜绝"亏损股因 PB 低而被误判为低估"。

四个分项（正 = 低估）：
U_rel = clamp((PB_peer / PB − 1)×100, −70, +150)  权重 0.40 —— 横向：相对同盈利能力同业
U_hist = clamp((PB_自身历史中位 / PB − 1)×100, −70, +150)  权重 0.30 —— 纵向：修复到自身 2018 年以来中枢
U_pe = clamp((PE_子行业中位 / PE_TTM − 1)×100, −70, +150)  权重 0.15 —— 仅 0<PE<200 时启用
Q_adj = clamp((ROE年化 − ROE_子行业中位)×1.0, −30, +30)  权重 0.15 —— 盈利能力溢价/折价
基础分 = 加权平均（缺失项按权重重新归一化）

盈利质量闸门（关键设计）：gate = clamp(ROE年化 / 5%, 0, 1)，仅作用于为正的 U_rel / U_hist。 ROE ≤ 0 时 gate = 0，亏损公司完全拿不到"低 PB = 便宜"的估值修复信用——低 PB 视为对其亏损的合理定价。ROE ≥ 5% 足额采信，0–5% 线性过渡。

调整项（直接加减，单位 pp）： 亏损扣分 clamp(ROE年化 × 1.5, −30, 0)； 业绩崩塌（净利同比 ≤ −50%）−15； 高杠杆（负债率 ≥75% / ≥70% / ≥65%）−8 / −5 / −3； 高成长（净利同比 ≥ +50% 且 ROE年化 ≥ 10%）+8。

低估幅度 = 基础分 + 调整项；正值 = 低估（隐含上行空间），负值 = 高估。合理价 = 现价 × (1 + 低估幅度/100)。

⚠️ 必须先说的四个局限

  • "低估幅度"是模型测算值，不是价格目标，也不是预测。它衡量的是：在"同子行业 + 同盈利能力 + 自身历史中枢"三重基准下，当前定价偏离了多少。换个基准就会得到不同数字。
  • 相对估值天生有"矮子里拔将军"的问题。若整个子行业都被高估，模型给出的"低估"只是"相对没那么贵"。结合 PB 历史分位（表中有该列）交叉验证更能看清绝对位置。
  • 半年报 ROE 已年化（×2），一季报（4 家）×4。年化处理对季节性强的公司会有偏差；H1 数据亦未经审计，可能包含非经常性损益。天齐锂业净利同比 +4925% 即为上年低基数所致，不代表可持续增速。
  • 模型无法识别"冶炼 vs 矿山"的结构性 PB 差异。恒邦股份（黄金冶炼）PB 1.63x 显著低于贵金属同业 6.5x，部分是商业模式差异（冶炼本就轻资产低溢价）而非错杀，需自行甄别。
